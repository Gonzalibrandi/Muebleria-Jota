# Hermanos Jota — E-commerce

Sitio de e-commerce front-end (HTML5, CSS3 y JavaScript) para Mueblería Hermanos Jota. Catálogo y carrito simulados en el cliente, sin backend.

## Integrantes

- Gonzalo Librandi
- Camilo Desza
- Ulises Manrique

## Funcionalidad

- **Inicio** (`index.html`): header, hero, productos destacados dinámicos, footer.
- **Catálogo** (`productos.html`): grilla de productos, datos locales, enlace a detalle, búsqueda (bonus).
- **Detalle** (`producto.html`): imagen, descripción, fabricación, precio, añadir al carrito.
- **Contacto** (`contacto.html`): formulario con validación JS y mensaje de éxito en el DOM.
- **Carrito simulado**: contador en el header.

## Tecnologías

- HTML5 semántico
- CSS3 (Mobile First, Flexbox)
- JavaScript (DOM, arrays de objetos, `async`/`setTimeout`, eventos)
